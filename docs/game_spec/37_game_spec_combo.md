# 37 ゲーム仕様メモ: ダメージとコンボ補正（BALDR SKY DiveX）

基本仕様をここにまとめる。出どころを各行に書く。【確定】= exe 解析または実機、【wiki】= 有志 wiki（ユーザー: 信頼性は非常に高い）、【推定】= データからの推定。

## ダメージ
* 1 ヒットのダメージ = max(⌊表示威力 × (100 − 累積補正) / 100⌋, 最低ダメージ)。【確定】調査記録 B4 §2、0x63ba40
* 表示威力 = 威力 ×1.5（甲以外の自機。MekaGroup 番号 ≠ 0）。甲は ×1.0。【確定】調査記録 18 N、0x63ba40
* 最低ダメージ（minDamage）には ×1.5 がかからない。【確定】調査記録 18 MINDMG（0x63bb1a / 0x63bb51）
* 累積補正がマイナスなら、そのまま 100% を超えて威力が上がる（上限なし。バグで甲のバイオブラスターを撃ち続けると一撃数百万）。【確定】ユーザー実機 11/10
* 装甲ゲージの減少 = max(1, 最終ダメージ × Hit int11 / 100)。【確定】調査記録 35

## コンボ補正（技ごと・ヒットごと）
* startComboCorrection（初段補正 / 基底）: コンボの最初の技のときだけ足される。【推定】docs/formats/05_waz_field_dictionary.md・B4
* midComboCorrection（ヒット毎補正）: ヒットごとに足される。【推定】
* endCorrection（技終了時）: 技が終わったときに足される。【推定】
* 甲の初段補正は「動いている敵への当てやすさ・ゴリ押しのしやすさ」で決まっている（装甲で押し込めるタックル等は +40、大振りのハンマー等は低いかマイナス、ボディブローのような技は中くらい）。コンボ内の役割とはあまり関係ない。【ユーザー見立て 11/10】

## FC とイニシャライザ【wiki】
* イニシャライザでコンボをもう 1 ループできる（ユーザー 11/10）。
* イニより前に、イニ以外の FC を使うと、累積補正は 0 にリセットされる。
* イニより後に、イニ以外の FC を使うと、累積補正は 50 にリセットされる。
* FC がヒットすると、FC 自身の補正が普通の武装と同じように足される。
* イニの補正は 25。イニは補正をリセットしない。
* 未確認: 二周目の最初の技に初段補正がもう一度かかるか。

## 甲の武装レベル
* Kou.waz は 1 武装につき Lv1 / Lv2 / Lv3 の 3 技が並ぶ（mek の wazSequence が Lv1、+1 が Lv2、+2 が Lv3）。威力は Lv1→Lv3 でおおむね 50→75→100 の比、フレーム数は Lv が上がると短くなる。FC・イニシャライザは Lv なし。【確定】docs/formats/05_waz_field_dictionary.md、Kou.waz の技名
* 透との比較は甲 Lv3 で行う（ユーザー 11/09）。

## BFE（原作）との違い
* BFE のヒットにある補正は「ｺﾝﾎﾞ補正」1 つだけ。初段だけの補正はない。【確定】調査記録 07
* BFE の式: dmg = max(威力 − 累積, 最低威力)、累積 += ｺﾝﾎﾞ補正（CPU 側は ×3/4）、HG で dmg += dmg × HG/130。DiveX では HG はオフ。【確定】調査記録 07・B4

## コンボの長さ（ユーザー 11/10）
* 武装枠は通常 12 + FC/イニシャライザ 2。通常 12 枠のうち 1 つは防御技で確定なので、攻撃技は 11。
* 一周目のコンボはだいたい 8 技つながる。イニ後は全技がまた使えるので 11 技出せる。

## 原作（BFE）の体験（ユーザー 11/10）
* 原作は、BU 以外の始動はあり得ないくらい、全プレイヤーがブーストアッパー始動に依存していた。移植でも BU 始動のコストは最小にする。
